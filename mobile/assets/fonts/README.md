# Download fonts from Google Fonts and place them here

## Required Fonts:

### Plus Jakarta Sans
- PlusJakartaSans-Regular.ttf (400)
- PlusJakartaSans-SemiBold.ttf (600)
- PlusJakartaSans-Bold.ttf (700)
- PlusJakartaSans-ExtraBold.ttf (800)

Download from: https://fonts.google.com/specimen/Plus+Jakarta+Sans

### Space Grotesk
- SpaceGrotesk-Regular.ttf (400)
- SpaceGrotesk-Medium.ttf (500)
- SpaceGrotesk-Bold.ttf (700)

Download from: https://fonts.google.com/specimen/Space+Grotesk

### Nunito
- Nunito-Regular.ttf (400)
- Nunito-SemiBold.ttf (600)
- Nunito-Bold.ttf (700)

Download from: https://fonts.google.com/specimen/Nunito

## Instructions:
1. Visit each Google Fonts link above
2. Click "Download family"
3. Extract the .ttf files
4. Place them in this folder (assets/fonts/)
5. Ensure file names match exactly as listed above
